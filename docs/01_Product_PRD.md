# ASTRA — Product Requirements Document (PRD)

**Document:** 01_Product_PRD.md
**Version:** 1.0.0
**Status:** Official Draft

## Purpose

This document defines the product vision for ASTRA, an AI-first personal fitness operating system.

## Version 1 Scope

- AI coaching
- Workout engine
- Workout logging
- Progress tracking
- Dashboard
- Recovery tracking
- Basic nutrition
- Offline-first workflow

## Out of Scope

- Multi-user support
- Social features
- Gamification
- Camera analysis
- Smartwatch integration

## Product Vision

ASTRA should become the first application opened before every workout.

## Core Principles

1. Evidence-based coaching.
2. One exercise at a time.
3. Offline-first workouts.
4. Structured data before conversation history.
5. Explain every recommendation.
6. User approval before major program changes.
